# Warm Burnout for Sublime Text

Your editor can stop irradiating your retinas too.

Warm Burnout provides native Sublime Text UI themes and color schemes. The UI themes cover the sidebar, panels, tabs, dialogs, status bar, and controls. The color schemes handle editor and syntax colors. Two variants are included: **Warm Burnout Dark** for the late shift and **Warm Burnout Light** for involuntary daylight.

## Install

1. In Sublime Text, select **Preferences: Browse Packages**.
2. Open the `User` directory.
3. Copy all four `.sublime-theme` and `.sublime-color-scheme` files into it:

   ```sh
   cp "Warm Burnout Dark.sublime-theme" \
      "Warm Burnout Light.sublime-theme" \
      "Warm Burnout Dark.sublime-color-scheme" \
      "Warm Burnout Light.sublime-color-scheme" \
      "/path/to/Packages/User/"
   ```

4. Select **Preferences: Select Theme**, then choose **Warm Burnout Dark** or **Warm Burnout Light**.
5. Select **Preferences: Select Color Scheme**, then choose the matching variant.

Sublime Text reloads themes and color schemes when the files change. Even this part does not need another restart ritual.

## What You Get

- Native JSON UI themes and color schemes for Sublime Text 4
- Warm sidebar, panels, tabs, dialogs, status bar, controls, and code-completion UI
- Editor background, cursor, selection, current line, invisibles, and gutter colors
- TextMate syntax scopes for comments, strings, regex, constants, keywords, functions, types, decorators, tags, CSS, Markdown, and Diff
- Bold structural keywords and tags
- Italic types, comments, decorators, CSS properties, and language variables

## Palette

Both schemes derive from the canonical Warm Burnout palette in the root [`AGENTS.md`](../AGENTS.md). Dark syntax tokens meet WCAG AAA against `#1a1510`. Light syntax tokens meet WCAG AA against `#F5EDE0`.
